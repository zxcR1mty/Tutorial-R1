Попробуй включить Vulkan — первые несколько запусков возможны кратковременные фризы, пока компилируются шейдеры, это нормально и проходит само.
02

Параметры запуска

Оптимальные параметры запуска для Steam. Они автоматически подгружают твой `autoexec.cfg` при старте, включают консоль и отключают лишние заставки.

Как добавить параметры запуска в Steam:
Зайди в библиотеку Steam -> ПКМ по Dota 2 -> Свойства -> "Параметры запуска".
Вставь туда эту строку:
+exec autoexec.cfg -language russian -novr -dx11 -nohltv -noaafonts -processheap -noborder -novid -console -map dota -prewarm
Ключевые команды:
• +exec autoexec.cfg — выполняет твой файл при старте игры.
• -console — открывает консоль сразу при входе в игру.
• -noborder — запускает игру в безрамочном окне (быстрый alt-tab без сворачивания игры).
03

Настройка Autoexec

Создание и редактирование файла `autoexec.cfg` для автоматической загрузки биндов и консольных команд при каждом входе в игру.

1. Где находится папка cfg:
Открой папку с игрой по пути (внутри папки Steam):
\dota 2 beta\game\dota\cfg

2. Скачай готовый пресет:
Нажми на кнопку ниже, чтобы скачать готовый файл `autoexec.cfg` с полным набором команд.
Скачать autoexec.cfg
3. Как заставить игру читать файл:
Добавь в параметры запуска Steam команду: -autoexec (но у нас в параметрах выше уже есть +exec autoexec.cfg).
Или открой консоль в игре и введи: exec autoexec.cfg
01
DENY

Денай крипов правым кликом

Убирает необходимость зажимать force-attack — денай крипа можно сделать обычным правым кликом.

Вбей в консоль или добавь в autoexec.cfg:

dota_force_right_click_attack 1
02
RUNE

Размер рун на мини-карте

Увеличивает иконки рун на мини-карте — проще заметить их появление боковым зрением, не всматриваясь.

Стандартное значение небольшое (в районе 500). Пример увеличенного размера:

dota_minimap_rune_size 750
Можешь подставить своё число вместо 750 — чем больше, тем крупнее иконки рун.
03
HP BAR

Мгновенное обновление HP-бара

Убирает плавное "доедание" полоски здоровья после урона — бар обновляется сразу, без задержки.

Вбей в консоль или добавь в autoexec.cfg:

dota_health_hurt_decay_time_max 0
04
COLOR

Цвета союзников и врагов

Свой RGB-цвет для команд — юниты, статы и хп-бары перекрашиваются под выбранный цвет.

Подвигай ползунки — квадраты покажут итоговый цвет, а команды ниже подстроятся сами:

Союзники
Враги
dota_friendly_color_r 0 dota_friendly_color_g 255 dota_friendly_color_b 0 dota_enemy_color_r 255 dota_enemy_color_g 0 dota_enemy_color_b 0
Цвет применится только если стоит dota_unit_use_player_color 0 (цвет по команде, а не по игроку).
Если отдельные команды (_r/_g/_b) не сработали — пиши цвет одной строкой: dota_friendly_color x x x и dota_enemy_color x x x, где вместо каждого x — своё число от 0 до 255.
05
CREEP

Размер крипов на мини-карте

Увеличивает иконки крипов на мини-карте — проще отследить крипволны и понять где сейчас идёт линия.

Важно: команда называется не "creep_size", а creep_scale — это множитель размера, а не пиксели. По умолчанию — 1.

dota_minimap_creep_scale 1.3
1.3 — крипы на 30% крупнее обычного. Можешь подставить своё значение, например 1.5 или 2.
